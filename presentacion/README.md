# Mussolini por dentro — presentación interactiva en 3D

**[▶ Abrir en línea](https://gutierrezsanchezjuand-commits.github.io/Sumo-Bot_Mussolini_2026_LLCC/presentacion/)**

Un modelo 3D de Mussolini que se puede girar y desarmar. Cada pieza (chasis, base, sensores IR,
sonar, IMU, IdeaBoard, motores, ruedas y pilas) tiene su ficha con lo que hace, cómo la usa el
código, una demo y los enlaces a la información completa. Incluye una sección del simulador.

- **Sin internet:** `index.html` es un solo archivo con todo adentro (el motor 3D, las fuentes y las
  imágenes). Se descarga y se abre con doble clic en Chrome, Edge o Firefox. También está en el
  [release](https://github.com/gutierrezsanchezjuand-commits/Sumo-Bot_Mussolini_2026_LLCC/releases/tag/presentacion-v1)
  como `mussolini_por_dentro.html`.
- **Video de 2 minutos** que la recorre:
  [mussolini_por_dentro.mp4](https://github.com/gutierrezsanchezjuand-commits/Sumo-Bot_Mussolini_2026_LLCC/releases/download/presentacion-v1/mussolini_por_dentro.mp4)
  (1080p, dos voces, subtítulos).
